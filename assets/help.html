🤖 YOLO AI 训练系统 · 操作使用说明

v1.0.0 ｜ 一站式从数据智能标注到模型一键训练、推理 ｜ 共 9 个功能模块 ｜ 左侧目录可跳转，也可点右上角「🌐 浏览器打开」查看完整排版

1. 系统总览

本软件是一个基于 PyQt5 的图形化 YOLO 工具箱，把「配环境 → 标数据 → 看分布 → 训练 → 验证 → 推理 → 导出」整条流程集中在一个窗口里完成，不需要手写命令行。

2. 快速上手路线

第一次使用，按下面顺序走一遍即可跑通全流程：

  1. 配环境：打开「⚙️ 环境配置」→ 保持默认环境名 yolo_env、Python 3.10 → 有 NVIDIA 显卡时勾选「使用GPU训练」→ 点 ⚙️ 一键配置环境。弹窗提示完成后，按提示在 Anaconda Prompt 里 conda activate yolo_env 并重新启动本程序。
  2. 准备数据：图片放一个文件夹。「✏️ 数据标注」→ 📁 打开图片文件夹 → 📂 打开标签文件夹（没有就先新建一个空文件夹）→ 在「🏷️ 类别与模型」里 🏷️ 标注类别管理 添加类别。然后 W 画框 或 🤖 AI预标注 快速起步。
  3. 查分布：「📊 标签统计」选择标签目录（可带数据集 YAML）→ 🚀 开始统计，确认类别均衡度与目标宽高比。
  4. 建数据集配置：手写 data.yaml（见 第 7 节），放到 datasets/你的数据集/。
  5. 训练：「🚀 模型训练」选权重与 data.yaml → 🚀 开始训练。
  6. 看结果：「📈 结果预览」选项目目录 runs/train → 勾选实验 → 查看配置/图表，或 📊 对比勾选实验。
  7. 验证效果：「🖼️ 图片推理」/「🎬 视频推理」填模型路径与内容 → 🚀 开始推理。
  8. 部署：「📦 模型导出」选 best.pt 与格式 → 🚀 开始导出。
软件自带示例数据 datasets/coco8（8 张图）与权重 weights/（yolo11n / yolo26n / yolov8n 等）、SAM2 模型 sam/sam2_s.pt，可先用它们把流程点通，再换自己的数据。

3. 环境配置（一键环境配置）

页面标题「⚙️ 一键环境配置」，副标题「自动配置YOLO训练所需的Python环境和依赖包」。它把装 Miniconda、建环境、装依赖这些最容易出错的命令全部图形化，日志与进度条实时可见。

3.1 参数说明

界面项含义默认值
📁 环境名称要创建/复用的 conda 环境名yolo_env
🐍 Python版本环境的 Python 版本3.10（建议保持 3.9~3.11）
📦 Conda路径指定 conda 可执行文件位置留空 = 自动检测
💻 硬件加速 →「使用GPU训练」勾选则安装 CUDA 版 PyTorch不勾选（装 CPU 版）

自动检测顺序：环境变量 %CONDA_EXE% → 依次在 %USERPROFILE%、C:\、D:\、E:\、F:\ 下查找 miniconda3/anaconda3\Scripts\conda.exe → 最后查 PATH。本机的 conda 若装在 E:\ProgramData\miniconda3 这类位置，也能被扫描到；扫描不到时把 conda.exe 完整路径填进「Conda路径」即可。

3.2 操作步骤

  1. 填写/确认上面四项参数，点 ⚙️ 一键配置环境。
  2. 观察「📊 安装进度」进度条与「📋 配置日志」。执行顺序固定为：检测 Conda（10%）→ 没有则下载安装 Miniconda（30%）→ conda create -n 环境名 python=版本 pip -y（40%）→ 依次安装 ultralytics、pyqt5、opencv-python、pyyaml（60/70/80/90%）→ 安装 torch torchvision（GPU 走 cu121 官方源，失败自动降级 CPU 版）→ 100%。
  3. 全部下载走清华 PyPI 镜像（https://pypi.tuna.tsinghua.edu.cn/simple），国内网络较快。
  4. 完成后弹窗给出三条后续操作：① conda activate 环境名；② 该环境 Python 解释器的绝对路径；③ 在激活后的环境中重新启动本程序，训练/推理才会用到新装的依赖。
注意：环境名已存在时不会报错，日志显示「环境 xxx 已存在」并继续装依赖；某个包安装失败不会中断流程，最后汇总为「环境已就绪，但以下依赖安装失败: …」，可对照日志单独重装。中途可点 ⏹️ 停止配置。
Python版本框不校验格式，随意填写会让创建环境失败；无显卡或不确定驱动版本时，建议先不勾 GPU，之后手动执行 pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121。

4.2 上手步骤

  1. 打开图片文件夹：支持 png / jpg / jpeg / bmp / webp / tiff / tif，按文件名自然排序，自动读取首张。
  2. 打开标签文件夹：标签写入这里。若未手动选择，默认落在图片目录路径后加 _labels 的同级文件夹。
  3. 建类别：点 🏷️ 标注类别管理 → ➕ 添加类别（输入「类别名称:」）→ 📥 导入类别文件（从 classes.txt 等每行一个类别的文本导入，可选合并或替换）→ 🗑 删除选中 → ✅ 确定。类别会自动写入 标签目录下的 classes.txt。
  4. 画框：勾选 ✏️ 画标注框(W) → 在图上左键按住拖拽出矩形，松开即生成并立即保存到该图的 .txt。过小的框（宽或高小于 0.01）会被忽略。切换类别只需在「类别查看/选择」下拉里选。
  5. 翻页：按 A/D 或点按钮；切换前会自动保存当前图标注，切走再回来不会丢。
  6. 删除：在「🖼️ 标注框列表」选中某框后按 Del 或点 🗑️ 删除选中框；🗑️ 删除所有框 会弹确认。没有撤销功能，误删只能重画。

4.3 AI 预标注（🤖）

用已有的 YOLO 权重先把图片批量标一遍，人工再修，效率远高于纯手画。弹窗内可设置：

项选项与默认
标注范围仅当前图片（默认） / 所有未标注图片 / 所有图片
写入模式追加（默认，保留已有框） / 覆盖（清空后写入）
模型：点击 📁 选 .pt；下拉列表自动扫描 weights/ 下不含 sam 的权重
置信度阈值 / NMS IoU默认 0.25（0.05~0.95）/ 0.7
跳过类别校验勾选后模型类别 ID 直接写入标签，类别名取模型输出并更新 classes.txt；会弹二次确认

点 🚀 开始标注 后台执行（可 ⏹ 停止）。每个框写成一行的 class_id cx cy w h（坐标归一化、6 位小数），并额外生成同名 .mark 文件标记该图由 AI 产出，方便后续人工复核与筛除。完成后自动刷新类别、画面与统计。

不勾选「跳过类别校验」时，模型输出的类别必须与 classes.txt 的行序一致（ID 从 0 计，第 i 行 = ID i）。不同模型内置类别顺序不同（例如 yolo11n.pt 的顺序与标准 COCO 并不完全相同），跨模型使用请优先用「跳过类别校验」或先对齐 classes.txt。

4.4 SAM 图片分割（✂️）

  1. 在「SAM模型:」下拉选择 SAM 权重（自动扫描 sam/ 与 weights/ 下名字含 sam 的 .pt，如 sam2_s.pt）。
  2. 点 ✂️ SAM图片分割 进入分割模式，此时会后台自动加载模型；在画面上 单击 是点提示（point prompt），拖框 是框提示（box prompt），返回的掩码自动转成外接矩形加入标注框。
  3. 按 Esc 或再次点击按钮退出。
模型较大时首次加载需要时间，加载未完成时点击会提示「SAM模型尚未加载完成，加载后请重新点击目标」，等提示消失后重新点击即可。

4.5 质检与 SAM 参数

  • 🔍 检查标注：弹框统计哪些图片已标注、哪些还是空的，用于收尾查漏。
  • ⚙️ SAM设置：分「✂️ SAM图像分割设置」和「🎬 SAM视频追踪设置」两组。图像组可改 推理图像尺寸(imgsz)（可选 256/512/768/1024/1280/1536/2048，默认 1024，越小越快、大目标越容易漏）；视频组含 质量预设（均衡默认 / 严格防漂移 / 快速运动 / 自定义）与 最小面积比、最大面积比、最小前后IoU、最大中心距离比、最大单帧面积比。「均衡」预设为 0.02 / 1.25 / 0.6 / 1.5 / 0.85。改动后点 💾 保存 写入 configs/sam_settings.json，↩️ 恢复默认 可回退。

5. SAM视频追踪（🎬）

页面说明：「首帧画框一次，SAM2 逐帧自动追踪，按帧导出图片与 YOLO 标签」。适合把一段视频快速变成几千张带标注的训练图。

5.1 界面控件

卡片控件说明
🎬 视频与输出🎬 选择视频、📂 选择输出目录、🖼 重新读取视频支持 mp4/avi/mov/mkv/flv/wmv，选完自动读首帧；输出默认在视频同目录的 视频名_tracking；重读视频会用首帧覆盖当前画面
🤖 模型与参数SAM2模型: 下拉、保存间隔: 每 N 帧默认 每 30 帧导出一次（范围 1~100000）；SAM2 模型放 sam/ 或 weights/
🎯 追踪目标目标列表、✏️ 修改选中类别、🎯 重新框选选中目标(需暂停)、⏹ 结束选中目标、🧹 清空所有目标列表项格式 #ID 类别名 [状态]，状态为 追踪中 / 已丢失 / 已结束，每个目标一种颜色

右侧状态标签、进度条、视频画布、时间轴日志、📂 打开输出目录画布实时显示带彩色轮廓的当前帧

5.2 上手步骤

  1. 🎬 选择视频 → 首帧出现在画布上。
  2. 确认或修改输出目录（📂 选择输出目录）。
  3. 在首帧上左键拖框画出第一个目标，弹出「设置类别」输入「类别名称:」；同名类别自动复用已有 ID，新名称递增分配 ID。可继续画多个目标。
  4. 🚀 开始追踪。逐帧运行 SAM2，画布与进度条、帧号同步更新。
  5. 追踪中仍可 直接画新框 追加目标。
  6. 目标跟丢（连续 15 帧未匹配）后列表显示「已丢失」。处理办法：点 ⏸ 暂停 → 在目标列表选中该目标 → 🎯 重新框选选中目标(需暂停) → 在当前帧重画一个正确的框 → 自动继续追踪。
  7. 目标离开画面不想再导出：⏹ 结束选中目标（该目标之后不再写入标签）。
  8. 结束后可 🧹 清空所有目标（需先停止追踪，弹确认）换一批目标重新跑。

按类别宽高比箱线框数 ≥20 的类别取 Top 15，比较各类别形状离散度与离群值

形态分档口径：宽高比 横长≤0.33 / 偏宽0.33~0.8 / 近方0.8~1.25 / 偏高1.25~3 / 竖长≥3；面积分档 小目标≤1% / 中小1~5% / 中大5~15% / 大目标≥15%（均为占整图比例）。

目录结构含 train/valid(或 val)/test 子目录时会分集统计并给出「数据范围」下拉切换；若子目录里没有标签，则回退为整目录递归统计。标签行不足 5 列（例如只写了 class）会被跳过，提示「未找到有效的 YOLO 标签框（需要 5 列：class cx cy w h）」。

页面说明：「配置训练参数，启动YOLO模型训练」。所有参数按卡片分组，鼠标悬停任意参数会显示它对应 ultralytics 的真实键名（如 epochs、lr0）。

7.1 卡片「📦 模型与数据」

界面项键默认值
模型路径:modelweights/yolo26n.pt（预训练权重，📁 选 .pt）
模型YAML:yamlultralytics/.../cfg/models/26/yolo26.yaml

同时填了「模型路径」和「模型YAML」时，行为是先按 YAML 搭网络结构再加载 .pt 权重（适合换类别数微调）；只填模型路径则直接加载完整模型（最常用，也最省事）。想跑自己类别数的模型，推荐只填 model 并在 data.yaml 里写 nc/names。

7.2 卡片「⚙️ 训练参数」

界面项键 / 默认怎么调
训练轮数epochs = 100（1~10000）小数据集 100~300；先用 50 轮试跑通
批次大小batch = 16显存不够就调小（8/4/2），或设 -1 自动
图像尺寸imgsz = 640（32~4096）目标很小（标签统计里宽/高 P95 < 0.05）时提高到 960/1280
设备device = 0单张显卡填 0，多卡填 0,1；无 GPU 必须改成 cpu，否则启动即报错
优化器optimizer = SGD（列表顺序 SGD / Adam / AdamW / NAdam）小数据集常换 AdamW 并把 lr0 降到 0.001
随机种子seed = 0固定后可复现实验
初始学习率lr0 = 0.01发散（loss 变 NaN）就下调到 0.001
最终学习率lrf = 0.01结束学习率 = lr0 × lrf
动量momentum = 0.937一般不动
早停耐心patience = 100（0~10000）验证指标连续多少轮无提升就停
保存周期save_period = 50每多少轮存一次中间权重
关闭马赛克close_mosaic = 10最后 N 轮关闭 Mosaic，利于收敛

7.3 卡片「🎨 数据增强」

界面项键 / 默认说明
色调hsv_v = 0.4实际为 HSV 明度扰动强度
旋转 / 平移 / 缩放 / 剪切 / 透视degrees 0.0、translate 0.1、scale 0.5、shear 0.0、perspective 0.0目标方向固定（如俯拍缺陷、文字）时保持 0，否则几何增强会引入无效样本
上下翻转 / 左右翻转flipud 0.0、fliplr 0.5类别语义与朝向有关（文字、上下区分的缺陷）时把对应项设 0

擦除 / 裁剪比例erasing 0.4、crop_fraction 1.0—

训练集比例fraction = 1.0做快速实验时可设 0.1 只取 10% 数据
IoU阈值 / 最大检测数iou 0.7、max_det 300NMS 相关，密集小目标可提高 max_det

7.4 卡片「🔧 其他选项」（复选框）

默认勾选：余弦学习率(cos_lr)、混合精度训练(amp)、保存权重(save)、显示标签(show_labels)、显示置信度(show_conf)、绘制图表(plot)、验证集评估(val)、详细输出(verbose)；默认不勾选：保存标签(save_txt)、保存置信度(save_conf)、保存裁剪图(save_crop)、可视化(visualize)。

「绘制图表」(plot) 必须勾选，否则「📈 结果预览」里看不到 results.png、混淆矩阵等图。「混合精度训练」在部分老显卡上有兼容问题，报错时可取消勾选。

7.5 运行、停止与配置复用

  1. 点 🚀 开始训练 → 后台线程启动训练，界面不卡死，「📋 训练日志」以等宽字体实时滚动输出；结束时写入 [完成] … 或 [错误] …。
  2. 运行中再点开始会提示「任务正在运行中」；数据集配置路径无效会提示「请选择有效的数据集配置文件」。
  3. 点 ⏹️ 停止训练（初始禁用，运行后可用）会请求 ultralytics 优雅停止当前 epoch，日志提示「正在停止训练...」。
  4. 💾 保存配置：把当前全部参数与路径存成 YAML，默认目录 configs/train_configs/（自动创建），默认文件名 train_config_年月日_时分秒.yaml，内含 __saved_at__ 时间戳。保存成功弹窗会说明「下次可通过「导入配置」一键载入」。
  5. 📥 导入配置：选择该 YAML 一键还原所有参数与路径（文件中没有的键保持当前值不动）。格式不是键值对时报「配置文件格式无效，应为键值对形式的 YAML」。

训练产物在 runs/train/实验名/：

runs/train/exp/
├── args.yaml        # 本次训练实际使用的全部参数
├── results.csv      # 逐轮指标（结果预览与曲线对比都读它）
├── weights/last.pt  # 最后一轮权重
├── weights/best.pt  # 验证指标最优权重 ← 推理/导出通常用这个
└── *.png            # results.png、混淆矩阵、标签相关图等（需勾选 plot）

9. 视频推理（🎬）

页面说明：「使用训练好的YOLO模型对视频进行目标检测」。与图片推理基本同构，差异如下：

  • 视频文件: 占位「请选择视频文件」，单选，支持 mp4/avi/mov/mkv。
  • 多一个 帧间隔:，默认 1（1~30）。设为 N 表示每 N 帧处理一次，可用于长视频提速；同时影响输出速度。
  • 复选框为 保存TXT 与 保存视频（默认勾选）。
  • 运行行有状态标签「当前帧: 0」（运行时递增）和 📂 打开输出视频（初始禁用，输出文件生成后才可点；未生成时提示「输出视频尚未生成」）。
  • 可视化区左「原始画面」右「检测结果」，逐帧实时刷新，没有暂停/播放控制；需要中止只能点 ⏹️ 停止。

输出：标注视频固定为 输出目录/video_output.mp4；勾选「保存TXT」时逐帧标签写到 输出目录/labels/000000.txt（按帧号命名）。

标签页能做什么

13. 常见问题 FAQ

Q1 点「开始训练/推理」立刻报 CUDA 或 device 相关错误

「设备」默认是 0（GPU 0）。没有 NVIDIA 显卡时必须手动改成 cpu；有显卡但驱动低于 CUDA 12.1，需在环境配置里改装 CPU 版 PyTorch 或自行安装匹配版本。

Q2 环境配置完成但训练仍提示找不到 ultralytics

依赖装在新 conda 环境里，而程序仍跑在旧解释器上。请按完成弹窗的三步：打开 Anaconda Prompt → conda activate yolo_env → 在该环境中重新运行 python main.py。

Q3 类别名称显示成「类别 0」而不是真实名称

标签统计页未选择「数据集YAML」，或 YAML 里没有 names。填了 classes.txt 时，请确保行序即 ID 序（第 1 行 = 0）。

Q4 AI 预标注出来的类别对不上

模型内置类别顺序与你的 classes.txt 不一致。二选一：先让 classes.txt 与模型顺序对齐；或勾选「跳过类别校验」，让软件用模型输出的类别名回写 classes.txt（会改动文件，弹窗会二次确认）。

Q5 SAM 点了没反应

模型正在后台加载，提示为「SAM模型尚未加载完成，加载后请重新点击目标」。等待数秒后重新点击；若下拉里没有任何 SAM 模型，把 sam2_*.pt 放进 sam/ 或 weights/。

Q6 视频追踪目标频繁「已丢失」

连续 15 帧匹配不上即判丢失。打开 ⚙️ SAM设置，把质量预设改为「快速运动」（放宽面积与位移限制）或「自定义」调小 最小前后IoU、放大 最大中心距离比；目标被遮挡时暂停后用 🎯 重新框选选中目标(需暂停) 补框。

Q7 训练目标太小、召回低

先看「标签统计」的宽/高 P5 分布：若归一化宽高普遍小于 0.05，把训练 imgsz 提到 960/1280 并相应调小 batch。

Q8 结果预览里看不到实验或没有图

实验目录必须有 args.yaml 才会进列表；图表来自训练时勾选「绘制图表」(plot) 生成的 PNG。若换了 project 目录，记得在顶部同步修改「项目目录」并点 🔄 刷新。

Q9 中文/图表显示为方块

绘图依赖系统中文字体（依次尝试 Microsoft YaHei、SimHei、SimSun）。Windows 一般自带；缺失时安装任一中文字体即可。
