## 2. 快速上手路线

1. **配环境**：「⚙️ 环境配置」→ 默认 `yolo_env` + Python `3.10` → 有 NVIDIA 显卡勾选「使用GPU训练」→ `⚙️ 一键配置环境`。完成后按弹窗 `conda activate yolo_env` 并**重新启动本程序**。
2. **准备数据**：「✏️ 数据标注」→ `📁 打开图片文件夹` → `📂 打开标签文件夹` → `🏷️ 标注类别管理` 添加类别 → `W` 画框或用 `🤖 AI预标注` 批量起步。
3. **查分布**：「📊 标签统计」→ 选标签目录 → `🚀 开始统计`。
4. **建 data.yaml**：见 [7.1](#71-模型与数据)。
5. **训练**：「🚀 模型训练」→ 选权重与 `data.yaml` → `🚀 开始训练`。
6. **看结果**：「📈 结果预览」→ 项目目录 `runs/train` → 勾选实验看配置/图表，或 `📊 对比勾选实验`。
7. **验证效果**：「🖼️ 图片推理」/「🎬 视频推理」→ `🚀 开始推理`。
8. **部署**：「📦 模型导出」→ 选 `best.pt` 与格式 → `🚀 开始导出`。

> 💡 仓库自带示例数据 `datasets/coco8`（8 张图）、权重 `weights/`（yolo11n / yolo26n / yolov8n 等）与 SAM2 模型 `sam/sam2_s.pt`、`sam/sam2_b.pt`。建议先用示例把流程点通，再换自己的数据。

## 3. 环境配置 ⚙️

页面标题「⚙️ 一键环境配置」，副标题「自动配置YOLO训练所需的Python环境和依赖包」。

### 3.1 参数

| 界面项 | 含义 | 默认值 |
|--------|------|--------|
| 📁 环境名称 | 要创建/复用的 conda 环境名 | `yolo_env` |
| 🐍 Python版本 | 环境的 Python 版本 | `3.10`（建议 3.9~3.11） |
| 📦 Conda路径 | conda 可执行文件位置 | 留空 = 自动检测 |
| 💻 硬件加速 →「使用GPU训练」 | 勾选则安装 CUDA(cu121) 版 PyTorch | 不勾选（CPU 版） |

自动检测顺序：`%CONDA_EXE%` → 在 `%USERPROFILE%`、`C:\`、`D:\`、`E:\`、`F:\` 下查找 `miniconda3/anaconda3\Scripts\conda.exe` → `PATH`。扫描不到时手动把 conda.exe 完整路径填入「Conda路径」。

### 3.2 步骤与执行流程

1. 确认参数，点 `⚙️ 一键配置环境`；随时可 `⏹️ 停止配置`。
2. 观察「📊 安装进度」进度条与「📋 配置日志」，执行顺序固定：

| 进度 | 动作 |
|------|------|
| 10% | 检测 Conda |
| 30% | 未找到则下载安装 Miniconda（`Miniconda3-latest-Windows-x86_64.exe`，静默安装到 `%USERPROFILE%\miniconda3`） |
| 40% | `conda create -n 环境名 python=版本 pip -y`（环境已存在则跳过并提示） |
| 60/70/80/90% | 依次安装 `ultralytics` → `pyqt5` → `opencv-python` → `pyyaml` |
| 90→100% | 安装 `torch torchvision`：GPU 走 `--index-url https://download.pytorch.org/whl/cu121`，失败自动降级 CPU 版 |

3. 全部下载走清华镜像 `https://pypi.tuna.tsinghua.edu.cn/simple`。
4. 完成弹窗给出三步：① `conda activate 环境名`；② 该环境 Python 解释器绝对路径；③ **在激活后的环境中重新启动本程序**，训练/推理才会用到新依赖。

> ⚠️ 单个包安装失败不会中断流程，最终汇总为「环境已就绪，但以下依赖安装失败: …」，可对照日志单独重装。
> ⚠️ Python 版本框不做格式校验，随意填写会导致创建环境失败。
> 💡 不确定显卡驱动时先装 CPU 版，之后手动执行 `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121`。

## 4. 数据标注 ✏️

页面说明：「手动框标注 / SAM 图片分割 / AI 预标注，支持类别管理与标注统计」。中间是图片画布，右侧一列功能卡片。

### 4.1 控件

| 位置 | 控件 | 作用 |
|------|------|------|
| 顶部工具行 | `📁 打开图片文件夹`、`📂 打开标签文件夹`、`🤖 AI预标注`、`🔍 检查标注`、`🎬 SAM视频追踪`、`⚙️ SAM设置` | 装载数据 / 批量预标注 / 质检 / 跳转视频追踪页 / SAM 参数 |
| 第二行 | `⬅ 上一张(A)`、`➡ 下一张(D)`、`✏️ 画标注框(W)`（开关按钮）、`✂️ SAM图片分割`（开关按钮）、状态标签 | 翻页与两种标注模式互斥切换 |
| 🏷️ 类别与模型 | `SAM模型:` 下拉、`类别查看/选择:` 下拉、`🏷️ 标注类别管理` | 选择绘制类别（显示 `ID. 类别名`，ID 从 0）、选 SAM 权重、增删类别 |
| 🖼️ 标注框列表 | 框列表、`🗑️ 删除选中框(Del)`、`🗑️ 删除所有框` | 查看/删除当前图的框 |
| 📁 文件列表 | 文件列表、`🗑️ 删除选中文件` | 点击跳转该图；删除图片原文件 |
| 📊 标注统计 | 摘要标签 + 只读明细 + `🔄 刷新统计` | 已标注张数、各类框数 |

### 4.2 手动标注步骤

1. **打开图片文件夹**：支持 `png/jpg/jpeg/bmp/webp/tiff/tif`，自然排序并自动显示首张。
2. **打开标签文件夹**：未选择时默认为图片目录路径后加 `_labels` 的同级文件夹。
3. **建类别**：`🏷️ 标注类别管理` → `➕ 添加类别`（填「类别名称:」）/ `📥 导入类别文件`（每行一个类别的 txt，可选**合并或替换**）/ `🗑 删除选中` → `✅ 确定`。类别自动写入 **标签目录下的 `classes.txt`**。
4. **画框**：勾选 `✏️ 画标注框(W)` → 左键拖拽出矩形 → 松手即生成并**立即保存**。宽或高小于 0.01 的过小框会被忽略。
5. **切类别**：在「类别查看/选择」下拉里选。
6. **翻页**：`A`/`D` 或按钮；**切换前自动保存**，离开页面（`hideEvent`）也会保存。
7. **删除**：列表选中后 `Del` 或 `🗑️ 删除选中框`；`🗑️ 删除所有框` 与 `🗑️ 删除选中文件` 会弹确认。**无撤销功能**，误删只能重画。

### 4.3 AI 预标注 🤖

用已有 YOLO 权重批量标注，人工只做修正。弹窗参数：

| 项 | 选项与默认 |
|----|-----------|
| 标注范围 | `仅当前图片`（默认）/ `所有未标注图片` / `所有图片` |
| 写入模式 | `追加`（默认，保留已有框）/ `覆盖` |
| 模型： | `📁` 选 `.pt`；下拉自动扫描 `weights/` 下不含 sam 的权重 |
| 置信度阈值 / NMS IoU | `0.25`（0.05~0.95）/ `0.7`（0.1~0.95） |
| 跳过类别校验 | 勾选后模型类别 ID 直接写入，类别名取模型输出并**更新 classes.txt**（弹二次确认） |

点 `🚀 开始标注` 后台执行（可 `⏹ 停止`）。每个框写成一行的 `class_id cx cy w h`（归一化、6 位小数），并生成同名 **`.mark`** 文件标记该图由 AI 产出，便于后续筛除。完成后自动刷新类别、画面与统计。

> ⚠️ 不勾选「跳过类别校验」时，模型类别必须与 `classes.txt` 行序一致（第 i 行 = ID i）。不同权重内置顺序可能不同（例如 `yolo11n.pt` 与标准 COCO 顺序并不一致），跨模型请优先用「跳过类别校验」或先对齐 `classes.txt`。
> ⚠️ 未选择标签文件夹时会提示「请先选择标签文件夹」。

### 4.4 SAM 图片分割 ✂️

1. 「SAM模型:」下拉选择权重（自动扫描 `sam/` 与 `weights/` 下名字含 `sam` 的 `.pt`）。
2. 勾选 `✂️ SAM图片分割` 进入分割模式，模型**在后台自动加载**。
3. 画面上 **单击** = 点提示（point prompt），**拖框** = 框提示（box prompt）；返回掩码自动转成外接矩形加入标注框。
4. `Esc` 或再次点击按钮退出。

> 模型较大时首次加载需数秒，期间点击会提示「SAM模型尚未加载完成，加载后请重新点击目标」。

### 4.5 质检与 SAM 参数

- `🔍 检查标注`：弹框统计已标注 / 未标注图片，收尾查漏。
- `⚙️ SAM设置`：分「✂️ SAM图像分割设置」与「🎬 SAM视频追踪设置」两组，各含 `推理图像尺寸(imgsz)`（256/512/768/1024/1280/1536/2048，默认 **1024**，越小越快但易漏小目标）。视频组含 `质量预设`（`均衡`默认 / `严格防漂移` / `快速运动` / `自定义`）与 `最小面积比`、`最大面积比`、`最小前后IoU`、`最大中心距离比`、`最大单帧面积比`；「均衡」预设为 `0.02 / 1.25 / 0.6 / 1.5 / 0.85`。`💾 保存` 写入 `configs/sam_settings.json`，`↩️ 恢复默认` 可回退。
- `🎬 SAM视频追踪`：直接跳转到视频追踪页。

## 5. SAM视频追踪 🎬

页面说明：「首帧画框一次，SAM2 逐帧自动追踪，按帧导出图片与 YOLO 标签」。适合把一段视频快速变成几千张带标注的训练图。

### 5.1 控件

| 卡片 | 控件 | 说明 |
|------|------|------|
| 🎬 视频与输出 | `🎬 选择视频`、`📂 选择输出目录`、`🖼 重新读取视频` | 支持 `mp4/avi/mov/mkv/flv/wmv`，选完自动读首帧；输出默认 `视频名_tracking`（视频同目录）；重读会用首帧覆盖当前画面 |
| 🤖 模型与参数 | `SAM2模型:` 下拉、`保存间隔: 每 N 帧` | 默认 **每 30 帧**导出一次（1~100000） |
| 🎯 追踪目标 | 列表、`✏️ 修改选中类别`、`🎯 重新框选选中目标(需暂停)`、`⏹ 结束选中目标`、`🧹 清空所有目标` | 列表项 `#ID 类别名 [状态]`，状态为 追踪中 / 已丢失 / 已结束，每目标一种颜色 |
| 运行行 | `🚀 开始追踪`、`⏸ 暂停`、`⏹ 停止`、`帧号: -  时间: -` | 暂停/停止未运行时禁用；暂停后按钮变 `▶ 继续` |
| 右侧 | 状态标签、进度条、视频画布、时间轴日志、`📂 打开输出目录` | 画布实时显示带彩色轮廓的当前帧 |

### 5.2 步骤

1. `🎬 选择视频` → 首帧出现在画布。
2. 确认/修改输出目录。
3. **在首帧左键拖框**画出目标 → 弹「设置类别」输入「类别名称:」（同名复用 ID，新名称递增 ID）。可继续画多个目标，框最小 5 像素。
4. `🚀 开始追踪` → SAM2 逐帧分割，画布、进度条、帧号同步更新。
5. 追踪中仍可**直接画新框**追加目标。
6. 目标连续 **15 帧**匹配失败即显示「已丢失」。处理：`⏸ 暂停` → 列表选中该目标 → `🎯 重新框选选中目标(需暂停)` → 在当前帧重画正确框 → 自动继续。
7. 目标离开画面不想再导出：`⏹ 结束选中目标`（之后该目标不写入标签）。
8. 结束后可 `🧹 清空所有目标`（需先停止追踪，弹确认）换一批目标重跑。

### 5.3 输出

```
输出目录/
├── images/frame_000000.jpg   # 每保存帧原图
├── labels/frame_000000.txt   # 同帧号 YOLO 标签 class_index cx cy w h（6 位小数，已结束的目标不写入）
└── session.json              # video_path / output_dir / sam_model / total_frames / fps / frames_processed / targets
```

> ⚠️ 拦截提示：「请先选择视频」「请先设置输出目录」「请先在首帧上框选追踪目标」「未找到SAM2模型，请将 sam2_*.pt 放入 sam/ 目录」「需要安装 opencv-python」「请先开始追踪…」「请先点击【暂停】…」「请先在列表中选中要补框的目标」「请先停止追踪后再清空目标」。

## 6. 标签统计 📊

页面说明：「统计数据集标签数量与目标框宽高分布，支持train/valid/test分割统计」。回答两个问题：**类别是否均衡**、**目标尺寸是否适合当前 `imgsz`**。

### 6.1 界面与产出

| 卡片 | 内容 |
|------|------|
| 输入 | `标签目录:`（占位「请选择标签目录」）+ `📁 浏览`；`数据集YAML:`（占位「可选：数据集YAML文件」）+ `📄 选择`（把类别 ID 映射为名称）；按钮 `🚀 开始统计` |
| 📈 类别数量统计 | 表格：类别ID、类别名称、各分割列（训练集/验证集/测试集）、总数 |
| 📐 宽高比与尺寸分布 | 整体摘要（总框数、宽、高、宽高比、形态分布、面积分布）+ 8 列表格：类别ID、类别名称、数量、`宽 均值/中位/P5~P95`、`高 均值/中位/P5~P95`、`宽高比 均值/中位/P5~P95`、宽范围、高范围 |
| 🖼️ 可视化图表 | `数据范围:`（全部数据 + 各分割）、`图表类型:`（5 种）、`💾 保存图表`、自适应画布 |
| 📋 操作日志 | 统计与保存过程文字记录 |

### 6.2 五种图表怎么看

| 图表 | 看什么 |
|------|--------|
| 类别数量分布 | Top 30 类别横向条形，识别样本过少的类别（补标或合并） |
| 宽高比分布直方图 | 对数横轴 `w/h` 分布，参考线 1.0、1/3、3；绝大多数目标应落在 0.33~3 |
| 宽/高分布直方图 | 左右两幅分别看归一化宽与高，标出均值/中位/P5/P95，用于估算最小目标像素尺寸 |
| 按类别 宽-高 散点 | 对数-对数坐标按类别着色（Top 12），参考线 W=H 与 3:1，区分细长类与方形类 |
| 按类别宽高比箱线 | 框数 ≥20 的类别取 Top 15，比较形状离散度与离群值 |

形态分档口径：宽高比 `横长≤0.33 / 偏宽0.33~0.8 / 近方0.8~1.25 / 偏高1.25~3 / 竖长≥3`；面积 `小目标≤1% / 中小1~5% / 中大5~15% / 大目标≥15%`（均为占整图比例）。

> 💡 目录含 `train`/`valid`(或 `val`)/`test` 子目录时分集统计并提供「数据范围」下拉切换；子目录无标签则回退整目录递归统计。
> ⚠️ 行不足 5 列的标签会被跳过，全部无效时提示「未找到有效的 YOLO 标签框（需要 5 列：class cx cy w h）」。未选 YAML 时类名显示为「类别 {id}」。

页面说明：「配置训练参数，启动YOLO模型训练」。参数按卡片分组，顶部是运行控制与日志，往下依次是「📦 模型与数据」「⚙️ 训练参数」「🎨 数据增强」「🔧 其他选项」，每卡 6 列网格排版。

### 7.1 模型与数据

| 界面项 | 键 | 默认值 |

| 模型YAML: | `yaml` | `ultralytics/.../cfg/models/26/yolo26.yaml` |

### 7.2 训练参数

| 界面项 | 键 / 默认 | 怎么调 |
|--------|-----------|--------|
| 训练轮数 | `epochs` = 100（1~10000） | 小数据 100~300；先 50 轮试跑通 |
| 批次大小 | `batch` = 16 | 显存不够调小到 8/4/2 |
| 图像尺寸 | `imgsz` = 640（32~4096） | 目标很小（标签统计宽/高 P95 < 0.05）时提到 960/1280 |
| 设备 | `device` = `0` | 单卡 0，多卡 `0,1`；**无 GPU 必须改 `cpu`** |
| 优化器 | `optimizer` = SGD（SGD / Adam / AdamW / NAdam） | 小数据集常换 AdamW 并把 lr0 降到 0.001 |
| 随机种子 | `seed` = 0 | 固定后可复现实验 |
| 初始学习率 | `lr0` = 0.01 | 发散（loss 变 NaN）降到 0.001 |
| 最终学习率 | `lrf` = 0.01 | 结束学习率 = lr0 × lrf |
| 动量 | `momentum` = 0.937 | 一般不动 |
| 早停耐心 | `patience` = 100（0~10000） | 验证指标连续多少轮无提升即停 |
| 保存周期 | `save_period` = 50 | 每多少轮存中间权重 |
| 关闭马赛克 | `close_mosaic` = 10 | 最后 N 轮关闭 Mosaic，利于收敛 |

### 7.3 数据增强

| 界面项 | 键 / 默认 | 说明 |
|--------|-----------|------|
| 色调 | `hsv_v` = 0.4 | 实际为 HSV **明度**扰动强度 |
| 旋转 / 平移 / 缩放 / 剪切 / 透视 | `degrees` 0.0 / `translate` 0.1 / `scale` 0.5 / `shear` 0.0 / `perspective` 0.0 | 目标方向固定（俯拍缺陷、文字）时保持 0 |
| 上下翻转 / 左右翻转 | `flipud` 0.0 / `fliplr` 0.5 | 类别语义与朝向有关时把对应项设 0 |
| 马赛克 / 混合 / 复制粘贴 | `mosaic` 1.0 / `mixup` 0.0 / `copy_paste` 0.0 | 数据少时提高后两者 |
| 擦除 / 裁剪比例 | `erasing` 0.4 / `crop_fraction` 1.0 | — |
| 自动增强 | `auto_augment` = `randaugment` | 留空则不传该参数 |
| 训练集比例 | `fraction` = 1.0 | 快速实验可设 0.1 |
| IoU阈值 / 最大检测数 | `iou` 0.7 / `max_det` 300 | 密集小目标可提高 max_det |

### 7.4 其他选项（复选框）

- **默认勾选**：余弦学习率 `cos_lr`、混合精度训练 `amp`、保存权重 `save`、显示标签 `show_labels`、显示置信度 `show_conf`、绘制图表 `plot`、验证集评估 `val`、详细输出 `verbose`
- **默认不勾选**：保存标签 `save_txt`、保存置信度 `save_conf`、保存裁剪图 `save_crop`、可视化 `visualize`

### 7.5 运行控制与配置复用

| 按钮 | 行为 |

## 14. 常见问题 FAQ

**Q1 点「开始训练/推理」立刻报 CUDA 或 device 相关错误**
「设备」默认 `0`（GPU 0）。无 NVIDIA 显卡必须手动改成 `cpu`；驱动低于 CUDA 12.1 时改装 CPU 版 PyTorch 或安装匹配版本。

**Q2 环境配置完成，但训练仍提示找不到 ultralytics**
依赖装在新 conda 环境，而程序仍跑在旧解释器上。按弹窗三步：Anaconda Prompt → `conda activate yolo_env` → 该环境中重新运行 `python main.py`。

**Q3 类别显示成「类别 0」而不是真实名称**
标签统计页未选「数据集YAML」，或 YAML 缺 `names`；标注页则检查标签目录 `classes.txt` 是否存在且行序即 ID 序。

**Q4 AI 预标注出来的类别对不上**
模型内置类别顺序与 `classes.txt` 不一致。二选一：对齐 `classes.txt` 顺序；或勾选「跳过类别校验」，让软件用模型输出类别名回写 `classes.txt`。

**Q5 SAM 点了没反应**
模型正在后台加载（提示「SAM模型尚未加载完成…」），等数秒重新点击；若下拉无模型，把 `sam2_*.pt` 放进 `sam/` 或 `weights/`。

**Q6 视频追踪目标频繁「已丢失」**
连续 15 帧匹配不上即判丢失。在 `⚙️ SAM设置` 把质量预设改为「快速运动」，或自定义调小 `最小前后IoU`、放大 `最大中心距离比`；被遮挡时暂停后用 `🎯 重新框选选中目标(需暂停)` 补框。

**Q7 小目标漏检、召回低**
先看「标签统计」宽/高 P5 分布：归一化宽高普遍 < 0.05 时，把训练 `imgsz` 提到 960/1280 并相应调小 `batch`。

**Q8 结果预览里看不到实验或没有图**
实验目录必须含 `args.yaml` 才进列表；图表来自训练时勾选「绘制图表」`plot` 生成的 PNG。换了 `project` 目录记得同步修改「项目目录」并 `🔄 刷新`。

**Q9 中文/图表显示为方块**
绘图依次尝试 Microsoft YaHei、SimHei、SimSun 字体；系统缺失中文字体时装任一个即可。

**Q10 想改帮助内容**
帮助文档就是 `assets/help.html`（纯静态、离线），用编辑器直接改文案后重新打开「ℹ️ 关于系统」即生效。
